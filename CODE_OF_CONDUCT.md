# Code of conduct

Be respectful, specific, and evidence-led. Harassment, discrimination,
threats, doxxing, credential disclosure, and deliberate disruption are not
accepted in project spaces.

Disagreements about architecture or security should focus on reproducible
behavior, source ownership, and stated trade-offs. Maintainers may edit or
remove harmful content and temporarily or permanently restrict participation.

Report conduct concerns privately to the repository maintainers. Do not place
private personal or security information in a public issue.
